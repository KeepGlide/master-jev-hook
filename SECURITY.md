# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.3.x (beta line, early access) | ✅ |
| 1.2.x (latest stable release) | ✅ |
| < 1.2 | ❌ |

## Reporting a vulnerability

Do not open a public issue or pull request for a vulnerability. Report it privately to [hello@keepglide.com](mailto:hello@keepglide.com) with the subject `Security: master-jev-hook`. Include the affected version, the steps to reproduce and the impact you expect. GitHub's private vulnerability reporting is not enabled on this repository yet; once it is, the Security tab of [KeepGlide/master-jev-hook](https://github.com/KeepGlide/master-jev-hook/security) becomes the preferred channel.

## Response time

We acknowledge a report within 7 days and aim to publish a fix or a mitigation within 30 days, depending on severity.
